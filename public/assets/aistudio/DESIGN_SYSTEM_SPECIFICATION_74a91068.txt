# 1. DESIGN PHILOSOPHY

## 1.1. Design Vision

NexaDesk harus memiliki tampilan seperti produk SaaS profesional yang matang, modern, dan premium.

Desain harus mengutamakan keterbacaan, kemudahan navigasi, konsistensi, serta efisiensi penggunaan.

Walaupun aplikasi memiliki banyak modul dan informasi, antarmuka tidak boleh terlihat padat, berantakan, atau membingungkan.

## 1.2. Design Characteristics

Karakteristik visual utama:

- Modern.
- Elegant.
- Minimalist.
- Professional.
- Clean.
- Sophisticated.
- Functional.
- Consistent.

## 1.3. Design Inspiration

Arah desain mengambil inspirasi dari karakteristik produk seperti:

- Linear: minimalisme dan konsistensi komponen.
- Stripe Dashboard: keterbacaan data dan pengelolaan informasi.
- Vercel Dashboard: layout bersih dan penggunaan whitespace.
- Modern Fintech Applications: visualisasi keuangan dan hierarki informasi.

Inspirasi tersebut hanya menjadi referensi arah desain, bukan untuk menyalin tampilan atau identitas visual produk lain.

## 1.4. Core Design Principles

**Clarity over Decoration**

Informasi harus lebih menonjol daripada dekorasi visual.

**Consistency over Complexity**

Seluruh halaman menggunakan standar visual dan interaksi yang sama.

**Whitespace is Important**

Berikan ruang yang cukup di antara elemen agar tampilan terasa lega.

**Data First**

Informasi bisnis, angka, tabel, dan grafik harus mudah dibaca.

**Subtle Interactions**

Gunakan animasi dan efek visual seperlunya.

# 4. TYPOGRAPHY SYSTEM

## 4.1. Primary Typeface

Inter.

Gunakan font Inter untuk seluruh antarmuka.

Jika font eksternal tidak tersedia, gunakan system sans-serif sebagai fallback.

## 4.2. Font Weights

| Weight | Value | Usage |
|---|---:|---|
| Regular | 400 | Body text |
| Medium | 500 | Labels |
| Semibold | 600 | Headings |
| Bold | 700 | Strong emphasis |

Hindari penggunaan font weight 700 secara berlebihan.

## 4.3. Typography Scale

| Style | Size | Weight |
|---|---:|---|
| Display | 32px | 700 |
| H1 | 28px | 600 |
| H2 | 24px | 600 |
| H3 | 20px | 600 |
| H4 | 16px | 600 |
| Body Large | 15px | 400 |
| Body | 14px | 400 |
| Small | 13px | 400 |
| Caption | 12px | 400 |
| Tiny | 11px | 500 |

## 4.4. Typography Rules

- Page title menggunakan 24–28px.
- Section heading menggunakan 16–20px.
- Body text menggunakan 14px.
- Supporting text menggunakan 12–13px.
- Angka KPI dapat menggunakan 26–32px.

- Hindari teks terlalu kecil untuk informasi penting.

# 12. MOTION & MICRO-INTERACTIONS

Animations should be subtle.

Recommended:
- Button hover transition: 150ms.
- Card hover: 150–200ms.
- Sidebar transition: 200ms.
- Modal entrance: 180–220ms.
- Dropdown transition: 120–150ms.

Interaction:
- Hover changes background or border.
- Focus shows visible focus ring.
- Active menu changes background and text color.
- Modal appears with subtle fade and scale.
- Toast enters and exits smoothly.

Avoid:
- Excessive bounce.
- Large zoom animations.
- Unnecessary parallax.
- Constant decorative animation.

Respect reduced-motion preferences.

# 14. ACCESSIBILITY

- Respect reduced motion.

# 17. FINAL DESIGN DIRECTIVE

NexaDesk must feel like a premium business SaaS product.

The interface should prioritize information clarity, operational efficiency, and visual consistency.

Do not generate generic admin dashboard designs.

Do not use excessive gradients, oversized illustrations, unnecessary glassmorphism, heavy shadows, or decorative colors.

Do not create a different visual style for each module.

Every page must follow the same design system.

The final result should be elegant, sophisticated, modern, professional, and practical for daily business operations.
